Политика конфиденциальности WarSpectra

Дата последнего обновления: 12 октября 2026 года.

1. Общая информация

WarSpectra — Discord-бот, предназначенный для автоматизации отдельных задач игрового сообщества Arma 3, включая создание приказов и документов о награждении.

2. Какие данные обрабатываются

В зависимости от используемых функций бот может обрабатывать идентификаторы Discord-пользователей и серверов, игровые позывные, звания, названия подразделений и сведения, введённые пользователями при создании документов.

Бот также использует технические данные, необходимые для выполнения команд и взаимодействия с Discord API.

3. Использование Google API

Для формирования документов WarSpectra использует Google Docs API и Google Drive API. Эти сервисы позволяют создавать документы на основе шаблонов, заполнять их данными и экспортировать результат.

Доступ предоставляется через авторизацию Google. Данные авторизации используются для работы приложения и не должны передаваться другим пользователям.

4. Хранение и удаление данных

Данные обрабатываются только в объёме, необходимом для работы соответствующих функций бота. Срок хранения зависит от типа данных и настроек используемых сервисов.

Временные документы удаляются после обработки, если операция завершается штатно. При ошибках отдельные файлы могут потребовать дополнительного удаления.

5. Передача данных

Данные передаются Discord и Google в объёме, необходимом для выполнения команд и работы соответствующих API. Мы не продаём персональные данные.

6. Безопасность

Учётные данные и токены доступа должны храниться в защищённом месте. Пользователям не следует публиковать секретные ключи, токены и другие данные авторизации.

7. Контакты

По вопросам конфиденциальности и обработки данных можно связаться с разработчиком по адресу: arsengaleewiq@gmail.com.
